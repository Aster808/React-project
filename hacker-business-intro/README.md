# Hacker Business Intro

A React + Vite intro page with animated orange code rain, a split-opening hacker wall, and a business-focused web development introduction.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
1. Extract this ZIP folder.
2. Open the extracted `hacker-business-intro` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL Vite prints, usually `http://localhost:5173/`.

Click **ENTER SYSTEM** to open the code wall and reveal the introduction. Click **REPLAY INTRO** to show it again.
